Key relevant Phase 2 integrated findings and evidence ledger are retained. Workstream C reconciles the material dispositions.
5. **Argon Phase 2 source map and old V2.6 integration note.** Not needed for first-line takeover; their relevant limitations and review coverage are summarized in the retained Phase 2 records and handoff guide.
6. **Arabic Amadeus addendum.** Excluded per founder instruction; the English addendum is authoritative.
7. Previous v1.0-specific README and checksum file. Replaced by this v1.1 README and newly generated SHA-256 manifest.

No included source report or source-baseline file has been edited. The approved Workstream C proposal and original Sonnet/Argon material are preserved as source documents. New governing/synthesis files are separately labelled v1.1/v1.0 and do not pretend to be original reviewer outputs.
